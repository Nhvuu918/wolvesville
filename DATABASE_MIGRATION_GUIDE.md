Thiết lập DATABASE_URL=postgresql://wolvesville:<password-URL-encoded>@127.0.0.1:5433/wolvesville trong shell riêng. `npm run build`; `npm run db:migrate` hai lần; `npm run test:pg:acceptance`; chạy full test bằng `WV_ARCHIVED_RULE_REGRESSION=1 WV_REQUIRE_POSTGRES=1 node --test tests/*.test.mjs` trên DB thử nghiệm riêng. Không dùng DB người chơi cho test. PG migrations 002,004–010 dùng ledger + advisory lock. Adapter live, concurrency, migration upgrade PG chưa được xác nhận. Không tự chuyển SQLite sang PG: chưa có công cụ ETL đã nghiệm thu; nếu cần chuyển dữ liệu cũ, giữ nguyên bản SQLite, xuất/đối soát riêng.

Backup PG: dùng công cụ backup của hosting hoặc `pg_dump --format=custom --file=wolvesville-backup.dump "$DATABASE_URL"` (credentials trong shell private). Restore vào database mới trống được cấp riêng: `pg_restore --exit-on-error --dbname="$RESTORE_DATABASE_URL" wolvesville-backup.dump`. Kiểm tra số hàng, Player ID, foreign keys, media và replay trước khi đổi URL. Không dùng --clean hay xóa volume. Bảo quản backup mã hóa, không đưa lên GitHub. Kiểm tra lịch backup/retention theo gói hosting và định kỳ thử restore. Chưa thực hiện live restore PG ở checkpoint này.
