# Sprint 12 local acceptance on Apple Silicon
Node >=22.13; npm install; cp .env.example .env. Set DB_PROVIDER=sqlite, WV_ENABLE_DEMO_AUTH=1, WV_OFFICIAL_RULE_TEST_MODE=1 for local restricted gameplay only. npm run verify:source; npm run test:12:all; npm run dev. For browser acceptance install Python Playwright and its Chromium (`python3 -m pip install playwright`, `python3 -m playwright install chromium`), then npm run test:browser:12:all. Use isolated PostgreSQL test database and existing environment configuration per SPRINT11_MACOS.md; npm run test:pg:12:all fails closed if unavailable. Never use production credentials or data.
