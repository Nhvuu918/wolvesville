# Run on Apple Silicon
Install Node.js >=22.13 and TypeScript (npm install --no-save typescript @types/node), Python 3 and Playwright for browser tests. From extracted source run `npm run verify:source`, `npm run build`, `npm run rules:build`, `npm run test:14:new`. For full backend run `npm run test:14:all`; metrics `npm run test:14:metrics`. Copy .env.example only for local setup; `npm run dev` starts server. Browser: install playwright (`python3 -m pip install playwright` and `python3 -m playwright install chromium`), then `npm run test:browser:14`. PostgreSQL needs isolated test server and configured connection; do not use production DB. See inherited README and env for configuration. Stable restricted QA baseline, not production. For all 17 browser suites use `npm run test:browser:14:all`. On macOS optionally set `WV_E2E_DIRECT=1` to use native HTTP/WS rather than the Linux QA bridge; native mode not tested in this environment.
